# Skill Usage Protocol

Every coding task performed by Jules must follow this protocol:

1. **Consultation**: Before writing UI code, read the relevant `SKILL.md` files in `agent-skills/`.
2. **Gatekeeping**: Reject any design that violates the principles of "Taste" or "Impeccable".
3. **Traceability**: In the commit message or task report, explain how a skill influenced a specific code change (e.g., "Applied Emil Kowalski's spring physics to the hero CTA").
4. **Iteration**: If a component feels "default" or "weak", consult the "21st.dev" skill to find a better variation.
