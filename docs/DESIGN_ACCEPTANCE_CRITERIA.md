# Design Acceptance Criteria

A UI task is considered "Accepted" only if it meets these criteria:

1. **Dark Cinematic Theme**: Consistent use of #0A0A0A background and bone/off-white text for premium projects.
2. **Mobile-First**: Layout must work perfectly on narrow viewports.
3. **Interaction Polish**: Every button and link must have a hover/tap state defined.
4. **No Placeholders**: Never commit empty divs or "TBD" text.
5. **Typography Hierarchy**: Clear distinction between H1, H2, and body copy using weight and spacing.
