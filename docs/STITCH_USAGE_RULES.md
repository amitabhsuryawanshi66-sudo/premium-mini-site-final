# Stitch Usage Rules

Stitch is to be used sparingly and only for visual direction.

1. **No Logic in Stitch**: Do not use Stitch for state management or complex logic.
2. **Visual Direction**: Use Stitch to generate color palettes, spacing concepts, or mood boards.
3. **Manual Implementation**: Jules must manually translate Stitch's visual suggestions into high-quality React code, ensuring it aligns with the "Impeccable" and "Emil Kowalski" skills.
4. **No MCPs**: MCP tools are strictly prohibited in this project foundation.
