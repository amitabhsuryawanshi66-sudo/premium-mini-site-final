# Impeccable Skill

## Principles
1. **Pixel Perfection**: No misaligned elements. Use consistent spacing scales.
2. **Typography is UI**: Hierarchy through weight, size, and color contrast.
3. **Correctness**: Every edge case must be handled (empty states, loading, errors).

## Guidelines
- Spacing: Use a 4px or 8px grid system.
- Contrast: Ensure AA/AAA accessibility standards for text.
- Layout: Use Flexbox/Grid for robust responsiveness.
- Focus: Interactive elements must have clear focus states.
