# Taste Skill

## Principles
1. **Reject Generic**: Do not use default AI-generated templates or generic components.
2. **Curation**: Choose components that fit the specific brand identity (e.g., cinematic for Obsidian).
3. **Nuance**: High-end design is found in the details (borders, shadows, micro-interactions).

## Guidelines
- Choose dark/light themes based on the niche (e.g., Luxury = Dark, Productivity = Light).
- Use high-quality imagery that feels editorial, not stock-like.
- Limit the use of shadows; use subtle borders or background offsets instead.
