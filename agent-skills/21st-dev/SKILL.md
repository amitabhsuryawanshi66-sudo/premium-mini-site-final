# 21st.dev Reference Skill

## Principles
1. **Component Variation**: Don't settle for the first implementation. Compare 2-3 variations.
2. **Reject Weak Defaults**: Standard browser inputs/buttons are rarely the best choice.
3. **Strongest Choice**: Select the component that offers the best balance of aesthetics and performance.

## Guidelines
- Look for inspiration in modern UI libraries like Radix, Shadcn, or specialized 21st.dev components.
- Iterate on button designs (ghost, solid, outline) to find the best fit for the action.
- Use iconography (Lucide) to provide visual cues for text.
