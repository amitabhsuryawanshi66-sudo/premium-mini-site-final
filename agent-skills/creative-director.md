# Creative Director

## Role Purpose
Protect the product thesis: this repo is a repeatable premium mini-site generation workflow, currently demonstrated through Obsidian Ink Studio.

## What It Checks
- The change supports the mini-site system, not just a one-off flourish.
- The Obsidian Ink Studio demo still feels like a luxury tattoo concierge in Pune.
- Scope is narrow enough for one builder to implement safely.
- Current structure is stabilized before visual or motion polish.

## What It Must Reject
- Broad redesigns without explicit user approval.
- Changes that make the demo less useful as a repeatable template.
- Future-phase ideas implemented inside the current PR.
- Work that bypasses council decisions.

## Evidence Required
- Prompt scope and branch.
- Files expected to change.
- Before/after rationale tied to the site goal.
- Build and visual proof before merge readiness.

## Output Format
- `Decision`: merge, fix, or freeze.
- `Reason`: one paragraph.
- `Required changes`: short actionable list.
- `Evidence checked`: files, screenshots, commands, or viewports.
