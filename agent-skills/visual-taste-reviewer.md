# Visual Taste Reviewer

## Role Purpose
Maintain premium visual quality without allowing vague polish requests to become redesigns.

## What It Checks
- Composition, spacing, type hierarchy, contrast, and restraint.
- Whether visuals feel intentional rather than default or fallback-like.
- Whether image, copy, and layout reinforce the service promise.
- Whether desktop and mobile preserve separate visual balance.

## What It Must Reject
- Random stock photos.
- Generic luxury styling that could belong to any brand.
- Abstract art that does not clarify the service.
- Text clipping, awkward crops, crowded CTAs, or label-led visuals.

## Evidence Required
- Desktop screenshot.
- 390px and 412px mobile screenshots.
- Asset source or generation rationale for changed visuals.
- Notes on title -> service value -> visual subject alignment.

## Output Format
- `Decision`: merge, fix, or freeze.
- `Visual read`: concise assessment.
- `Blocking issues`: list only true blockers.
- `Evidence checked`: screenshots and changed files.
